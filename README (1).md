# Сайт Лили Гуцеловой

Статический сайт (HTML + CSS), сборка не нужна.

## Структура
- `index.html` — вся страница: кратко, затем подробный рассказ
- `assets/` — логотип, фото, фон

## Как выложить на GitHub Pages
1. Создайте репозиторий на github.com (например, `lili-site`).
2. Нажмите **Add file → Upload files**, перетащите **содержимое** папки (включая `assets` и `.nojekyll`) и нажмите **Commit changes**.
3. Откройте **Settings → Pages**.
4. В **Source** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/lili-site/`.

Свой домен можно подключить там же, в Settings → Pages → Custom domain.
